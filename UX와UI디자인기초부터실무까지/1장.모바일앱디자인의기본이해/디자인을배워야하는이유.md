# **UX/UI 디자인을 배워야 하는 이유**

## **1. UX/UI란?**

### **UI (User Interface)**

사용자 인터페이스로, 사용자가 제품이나 서비스와 상호작용하는 화면 요소를 의미한다.

- 버튼
- 뒤로 가기
- 키패드
- 이미지
- 텍스트
- 화면 구성 요소

### **UX (User Experience)**

사용자 경험으로, 화면을 통해 경험하는 것과 서비스를 사용하면서 겪는 전반적인 경험을 의미한다.

- 서비스 사용 과정에서 느끼는 경험
- 사용자가 목적을 달성하는 과정
- 서비스 이용의 편리성과 만족도

UI와 UX는 서로 밀접한 관계가 있으며, 두 영역에 대한 지식의 균형이 중요하다.

## **2. 강의 대상**

- UX/UI 디자이너 취업을 준비하는 예비 디자이너
- 디자인 지식을 배우고 싶은 개발자
- 앱 기획자, PM, PO
- 본인만의 앱 서비스 창업을 준비하는 예비 창업자

## **3. UX/UI가 중요한 이유**

### **3-1. IT 서비스의 성장**

- 스마트폰 보급과 인터넷 및 다양한 기기의 발달로 앱 서비스가 증가한다.
- 하나의 앱 서비스가 하나의 기업으로 성장하는 시대이다.
- 다양한 앱 서비스의 등장으로 UX/UI 전문 인력의 수요가 증가한다.

### **3-2. IT 서비스업의 창업 접근성**

제조업과 IT 서비스업은 창업 과정에서 필요한 비용, 시간, 리스크에 차이가 있다.

| 구분      | 제조업                         | IT 서비스업                              |
| --------- | ------------------------------ | ---------------------------------------- |
| 초기 비용 | 공장, 부지, 자재 등 필요       | 비교적 적은 인원으로 개발 가능           |
| 개발 기간 | 시제품 제작까지 오랜 시간 소요 | 핵심 기능 중심으로 빠르게 출시 가능      |
| 리스크    | 시간과 비용 부담이 큼          | MVP 출시 후 시장 반응 확인 가능          |
| 접근성    | 물리적 생산 및 유통 제약       | 앱 마켓을 통해 다양한 지역에서 이용 가능 |

IT 서비스는 핵심 기능을 MVP로 출시하고 사용자 반응을 확인한 후 개선하거나 방향을 변경할 수 있다.

### **3-3. 앱 서비스의 일상화**

- 중고거래, 송금, 부동산, 교육, 의료, 여가 등 다양한 분야에서 앱 서비스가 활용된다.
- 앱 서비스는 일상생활을 더욱 편리하게 만든다.
- 사용자가 앱에 소비하는 시간이 증가하면서 서비스의 영향력이 커지고 있다.

### **3-4. 앱 서비스의 수익 구조**

앱 서비스의 주요 수익 모델은 다음과 같다.

- 광고
- 거래 수수료
- 구독료

사용자가 많아질수록 매출 증가 가능성이 높아지며, 기업은 활성 사용자 수와 재방문율, 사용 시간을 높이기 위한 전략을 수립한다.

## **4. UX/UI 디자이너의 역할**

### **4-1. 사용자의 목적 달성 지원**

사용자가 원하는 목적을 쉽게 달성할 수 있도록 디자인한다.

- 서비스의 가치를 전달한다.
- 사용자가 서비스를 다시 방문하도록 유도한다.
- 사용자가 서비스 내에서 원하는 행동을 수행하도록 설계한다.

### **4-2. 기업의 이윤 증대**

기업의 목표에 맞게 사용성을 개선한다.

- 회원가입률 증가
- 객단가 증가
- 구매 전환율 증가
- 재방문율 증가
- 앱 설치 유도
- 사용 시간 증가

### **4-3. 사용자 행동 분석**

사용자의 행동과 니즈를 파악하기 위해 다음을 활용한다.

- 정량적 데이터
- 정성적 데이터
- 사용자의 목표
- 무의식적인 행동
- 충족되지 않은 니즈

### **4-4. 협업**

UX/UI 디자이너는 혼자 일하는 것이 아니라 다양한 직군과 협업한다.

- 개발자
- 매니저
- 리서처
- 기타 서비스 관련 전문가

다양한 분야의 지식을 갖추면 협업 과정에서 도움이 된다.

## **핵심 정리**

UX/UI 디자이너는 사용자가 원하는 목적을 달성하도록 돕고, 동시에 기업의 서비스 목표와 수익성을 고려해 사용성을 개선한다. 이를 위해 사용자 행동과 니즈를 데이터로 분석하고, 다양한 직군과 협업하여 서비스를 발전시킨다.
