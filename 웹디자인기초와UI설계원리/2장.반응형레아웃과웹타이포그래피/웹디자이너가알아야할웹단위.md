# **웹디자이너가 알아야 할 웹 단위: px, rem, %, vw, vh**

## **1. 웹에서는 왜 여러 단위를 사용할까?**

웹사이트는 데스크톱, 태블릿, 스마트폰 등 다양한 화면에서 표시돼.

모든 크기를 고정된 px로 지정하면 화면 크기가 달라졌을 때 레이아웃이 어색해질 수 있어.

따라서 **요소의 크기를 고정할지, 부모 영역이나 화면 크기에 맞춰 변경할지**에 따라 단위를 선택해야 해.

## **2. 자주 사용하는 웹 단위 비교**

| 단위  | 기준                  | 주요 사용처               |
| ----- | --------------------- | ------------------------- |
| `px`  | 고정된 크기           | 버튼, 아이콘, 정밀한 간격 |
| `em`  | 부모 요소의 글자 크기 | 컴포넌트 내부 상대 크기   |
| `rem` | HTML 루트 글자 크기   | 폰트, 여백, 디자인 시스템 |
| `%`   | 부모 영역             | 반응형 너비, 영역 분할    |
| `vw`  | 브라우저 너비         | 화면 너비 기준 크기       |
| `vh`  | 브라우저 높이         | 화면 높이 기준 섹션       |

## **3. 단위별 상세 정리**

### **① px (Pixel)**

고정 크기

정확하게 유지해야 하는 요소에 사용하는 단위.

**사용 예시**

- 버튼: `120px × 48px`
- 아이콘: `24px × 24px`
- 요소 사이 간격: `20px`

```
.button {
  width: 120px;
  height: 48px;
}
```

피그마 역시 픽셀 기반이므로 디자인 작업에서 px를 사용하는 것은 자연스러워.

다만 모든 요소를 px로 고정하지 않는 것이 중요해.

### **② em**

부모 요소 기준

부모 요소의 글자 크기를 기준으로 계산하는 상대 단위야.

예를 들어 부모의 글자 크기가 20px이라면:

- `1em` = 20px
- `2em` = 40px
- `0.5em` = 10px

```
.parent {
  font-size: 20px;
}

.child {
  font-size: 1em;
  padding: 1em;
}
```

부모의 글자 크기가 변경되면 자식 요소의 em 기반 크기도 영향을 받아.

컴포넌트의 글자 크기와 내부 여백을 함께 조절할 때 활용할 수 있어.

### **③ rem**

디자인 시스템에서 유용

문서의 루트 요소인 `html`의 글자 크기를 기준으로 계산하는 상대 단위야.

기본값이 16px이라면:

| 단위     | 실제 크기 |
| -------- | --------- |
| `0.5rem` | 8px       |
| `1rem`   | 16px      |
| `1.5rem` | 24px      |
| `2rem`   | 32px      |
| `3rem`   | 48px      |

```
html {
  font-size: 16px;
}

.title {
  font-size: 2rem; /* 32px */
}

.container {
  padding: 1.5rem; /* 24px */
}
```

루트 글자 크기를 18px로 변경하면 `2rem`은 36px이 돼.

**장점**

- 폰트와 여백을 일관된 규칙으로 관리 가능
- 기준값 변경으로 전체 크기 조절 가능
- 디자인 시스템과 반응형 작업에 유용

### **em vs rem**

| 구분      | em                           | rem                     |
| --------- | ---------------------------- | ----------------------- |
| 기준      | 부모 요소의 글자 크기        | 루트 요소의 글자 크기   |
| 영향 범위 | 부모의 영향을 받음           | 루트 기준으로 계산      |
| 특징      | 중첩 구조에서 크기 변화 가능 | 일관된 크기 관리에 유리 |

### **④ % (Percentage)**

부모 영역 기준

부모 요소의 크기를 기준으로 비율을 계산해.

예를 들어 부모 너비가 1200px이라면:

- `50%` = 600px
- `100%` = 1200px

**부모 영역을 50:50으로 분할**

부모 너비 1200px

**50%**

600px

**50%**

600px

**사용 예시**

- 이미지와 텍스트를 50:50으로 배치
- 카드 너비를 부모 영역에 맞춰 조절
- 콘텐츠 영역을 화면에 맞게 채우기

```
.container {
  width: 100%;
  max-width: 1200px;
}

.image {
  width: 50%;
}
```

### **⑤ vw / vh**

브라우저 화면 기준

부모 요소가 아니라 현재 브라우저 화면(Viewport)을 기준으로 계산해.

- `vw`: Viewport Width
- `vh`: Viewport Height

| 단위    | 의미             |
| ------- | ---------------- |
| `100vw` | 화면 너비의 100% |
| `50vw`  | 화면 너비의 50%  |
| `100vh` | 화면 높이의 100% |
| `70vh`  | 화면 높이의 70%  |

**사용 예시**

```
.hero {
  width: 100vw;
  height: 70vh;
}
```

히어로 영역을 브라우저 화면 높이의 70%만큼 차지하도록 만들 수 있어.

### **% vs vh**

**70%**

**70%**

부모 요소의 높이를 기준으로 계산

**70vh**

**70vh**

브라우저 화면 높이를 기준으로 계산

- `70%` = 부모 요소 높이의 70%
- `70vh` = 브라우저 화면 높이의 70%

따라서 화면 전체를 기준으로 높이를 설정하고 싶다면 vh를 고려하면 돼.

### **⑥ 화면 높이에서 특정 영역 제외하기**

실무에서는 화면을 꽉 채우되 헤더 높이만큼 제외해야 하는 상황도 있어.

```
.main {
  height: calc(100vh - 80px);
}
```

헤더가 80px이라면 화면 높이에서 80px을 제외한 영역을 사용할 수 있어.

## **4. 어떤 단위를 사용하면 좋을까?**

| 목적                       | 추천 단위 | 예시                |
| -------------------------- | --------- | ------------------- |
| 정확한 크기 유지           | `px`      | 버튼, 아이콘        |
| 폰트와 여백의 일관된 관리  | `rem`     | 제목, 패딩          |
| 부모 영역에 맞춰 조절      | `%`       | 이미지, 컬럼        |
| 부모 글자 크기에 따라 조절 | `em`      | 컴포넌트 내부 여백  |
| 화면 너비 기준             | `vw`      | 전체 화면 너비      |
| 화면 높이 기준             | `vh`      | 히어로, 로그인 화면 |

참고로 모바일 브라우저에서는 주소창 등으로 인해 `100vh`가 실제 보이는 영역과 다를 수 있어. 최신 CSS에서는 `100dvh`를 활용해 동적으로 변하는 화면 높이에 대응할 수도 있어.

## **5. 프론트엔드 연결**

실제 개발에서는 여러 단위를 목적에 맞게 함께 사용해.

```
html {
  font-size: 16px;
}

.container {
  width: 100%;
  max-width: 1200px;
  padding: 1.5rem;
  margin: 0 auto;
}

.button {
  width: 120px;
  height: 48px;
}

.hero {
  min-height: 70vh;
}
```

## **핵심 요약**

1. `px`: 정확하게 고정해야 하는 크기
2. `em`: 부모 요소의 글자 크기 기준
3. `rem`: 루트 요소의 글자 크기 기준
4. `%`: 부모 영역을 기준으로 비율 계산
5. `vw`: 브라우저 화면 너비 기준
6. `vh`: 브라우저 화면 높이 기준

**가장 중요한 개념:** 웹 단위는 단순한 숫자 표기가 아니라, 화면 크기가 달라져도 디자인 의도를 유지하기 위한 방법이야.
