# **스페이싱과 사이징**

## **1. 스페이싱과 사이징**

- **Spacing**: 요소와 요소 사이의 거리
- **Sizing**: 버튼, 아이콘, 입력창 등 요소 자체의 크기

일관된 간격과 크기 규칙을 사용하면 UI가 정돈되어 보인다. 매번 임의의 숫자를 사용하는 대신 자주 사용하는 값을 정해 반복해서 사용한다.

## **2. Margin, Padding, Gap의 차이**

| 구분    | 의미                    | 예시                        |
| ------- | ----------------------- | --------------------------- |
| Margin  | 요소 바깥쪽 여백        | 카드와 카드 사이, 섹션 사이 |
| Padding | 요소 안쪽 여백          | 카드 테두리와 콘텐츠 사이   |
| Gap     | 나열된 요소 사이의 간격 | 아이콘과 텍스트, 카드 목록  |

- **Margin**은 서로 다른 요소나 그룹 사이의 거리이다.
- **Padding**은 하나의 요소 내부에서 콘텐츠가 배치되는 공간이다.
- **Gap**은 여러 요소가 나열될 때 요소 사이에 적용되는 간격이다.

## **3. 간격은 정보를 그룹화한다**

스페이싱은 단순히 화면에 여유 공간을 만드는 것이 아니라 정보 간 관계를 표현한다.

이는 게슈탈트의 **근접성 원리**와 관련이 있다.

- 같은 그룹 → 간격을 좁게
- 다른 그룹 → 간격을 넓게

가까이 배치된 요소는 서로 관련된 정보로 인식되고, 멀리 떨어진 요소는 다른 그룹으로 인식된다.

## **4. 4포인트 그리드**

4px을 기본 단위로 사용해 일정한 간격 규칙을 만드는 방법이다.

## **Spacing Scale**

| 크기      | 활용 예시            |
| --------- | -------------------- |
| 4px       | 아이콘과 텍스트 사이 |
| 8px       | 작은 내부 간격       |
| 12px      | 관련 요소 사이       |
| 16px      | 기본 패딩            |
| 24px      | 콘텐츠 그룹 사이     |
| 32px      | 큰 그룹 사이         |
| 40px 이상 | 섹션 사이            |

모든 값을 사용하는 것이 아니라 프로젝트에서 자주 사용하는 값만 선택해 규칙을 만든다.

## **5. 사이징 규칙**

요소 자체의 크기도 일정한 규칙을 사용한다.

예를 들어 아이콘 크기를 매번 17px, 21px, 25px로 지정하기보다 일정한 사이즈 스케일을 사용한다.

| 크기 | 예시        |
| ---- | ----------- |
| 16px | 작은 아이콘 |
| 20px | 기본 아이콘 |
| 24px | 강조 아이콘 |
| 32px | 큰 아이콘   |

버튼, 입력창, 드롭다운 등의 높이도 규칙을 정해 통일한다.

같은 화면에서 컴포넌트마다 높이가 다르면 나란히 배치했을 때 정렬이 어색해질 수 있다.

## **6. 반응형 스페이싱**

화면 크기에 따라 간격과 크기도 함께 조정한다.

- 섹션 간격 조절
- 좌우 패딩 조절
- 카드 사이 Gap 조절
- 콘텐츠 밀도 조절

모바일에서는 화면이 좁아지므로 데스크톱의 여백을 그대로 사용하면 콘텐츠 공간이 부족해질 수 있다.

## **7. 모바일 터치 영역**

모바일은 마우스가 아닌 손가락으로 조작하므로 터치 영역을 충분히 확보한다.

- 모바일 버튼의 터치 영역은 약 44\~48px 이상 확보한다.
- 작은 버튼은 모바일에서 더 크게 조정할 수 있다.
- 반응형 디자인은 단순히 화면을 축소하는 것이 아니라 사용 환경에 맞게 크기를 조정하는 작업이다.

## **8. 디자인 토큰으로 관리하기**

자주 사용하는 간격과 크기를 디자인 토큰으로 정의하면 일관성을 유지하고 수정하기 쉽다.

### **Primitive Token**

기본 숫자 값을 정의한다.

| Token     | Value |
| --------- | ----- |
| Spacing 1 | 4px   |
| Spacing 2 | 8px   |
| Spacing 3 | 12px  |
| Spacing 4 | 16px  |
| Spacing 5 | 20px  |
| Spacing 6 | 24px  |

### **Alias Token**

기본 값을 실제 UI의 용도에 연결한다.

| Token     | 용도              |
| --------- | ----------------- |
| Padding S | 작은 내부 여백    |
| Padding M | 기본 내부 여백    |
| Gap S     | 작은 요소 간 간격 |
| Gap M     | 기본 요소 간 간격 |
| Margin L  | 큰 그룹 사이 간격 |

디자인과 개발이 동일한 토큰을 사용하면 화면마다 다른 숫자를 임의로 지정하는 것을 방지할 수 있다.

## **핵심 정리**

- **Spacing**은 요소 사이의 거리, **Sizing**은 요소 자체의 크기이다.
- Margin, Padding, Gap은 각각 바깥 여백, 안쪽 여백, 요소 간 간격을 의미한다.
- 간격은 정보의 그룹과 관계를 표현한다.
- 4포인트 그리드로 간격 규칙을 만든다.
- 반응형에서는 화면 크기와 사용 환경에 맞게 간격과 크기를 조정한다.
- 디자인 토큰을 활용해 디자인과 개발이 동일한 규칙을 공유한다.
