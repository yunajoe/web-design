# **웹에서 잘 읽히는 타이포그래피 설계하기**

## **1. 타이포그래피의 핵심은 정보의 위계**

웹에서 사용자는 텍스트를 먼저 읽고 정보를 판단해.

따라서 좋은 타이포그래피는 예쁜 폰트를 선택하는 것보다 **무엇을 먼저 읽어야 하는지 시각적으로 구분하는 것**이 중요해.

예를 들어 다음과 같은 위계가 있어.

1. 제목
2. 본문
3. 설명
4. 보조 정보

이미지와 색상을 제거해도 텍스트의 중요도가 구분되어야 해.

## **2. 타이포그래피를 구성하는 다섯 가지 요소**

| 요소                 | 역할                        |
| -------------------- | --------------------------- |
| 폰트 크기            | 정보의 중요도 구분          |
| 행간(Line Height)    | 줄과 줄 사이의 간격 조절    |
| 자간(Letter Spacing) | 글자 사이의 간격 조절       |
| 폰트 종류            | 서비스 분위기와 가독성 결정 |
| 폰트 두께·명도 대비  | 강조 및 보조 정보 구분      |

## **3. 폰트 크기와 위계 설정**

페이지마다 폰트 크기를 감으로 지정하기보다 역할별로 규칙을 정하는 것이 좋아.

예시:

`Headline → Title → Body → Label → Caption`

### **Typography Scale**

폰트 크기를 일정한 비율로 증가시키는 방법이야.

강의에서는 본문을 16px(1rem)로 설정하고 약 1.25배씩 키우는 예시를 사용해.

**폰트 스케일 예시**

Caption · 12px

**보조 설명**

Label · 14px

**항목 이름**

Body · 16px

**본문 내용**

Title · 20px

**섹션 제목**

Headline · 25px

**페이지 제목**

Display · 31px

**주요 메시지**

이해를 돕기 위한 크기 체계 예시이며, 강의에서 제시한 고정 규격은 아니야.

- 랜딩 페이지: 제목과 본문의 크기 차이를 크게 설정할 수 있음
- 웹 애플리케이션: 많은 정보를 보여주므로 크기 차이를 좁게 설정할 수 있음
- 중요한 것은 필요한 크기 단계만 사용하는 것

### **반응형 폰트 크기**

화면 크기에 따라 폰트 크기도 조정할 수 있어.

강의의 예시:

| 화면     | 기본 폰트 크기 |
| -------- | -------------- |
| 데스크톱 | 16px           |
| 태블릿   | 15px           |
| 모바일   | 14px           |

위 값은 예시이며, 서비스에 맞게 조정해야 해.

## **4. 행간(Line Height)**

행간은 줄과 줄 사이의 간격이야.

텍스트의 종류에 따라 다르게 설정하는 것이 좋아.

**행간 비교**

좁은 행간

웹 타이포그래피는 글을 읽기 쉽게 만드는 것이 중요해. 행간이 너무 좁으면 다음 줄을 구분하기 어려워.

넉넉한 행간

웹 타이포그래피는 글을 읽기 쉽게 만드는 것이 중요해.\
\
행간이 넉넉하면 다음 줄을 구분하기 쉬워.

| 텍스트 종류 | 강의 예시                 |
| ----------- | ------------------------- |
| 제목        | 120\~150%                 |
| 긴 본문     | 180\~200%                 |
| 버튼·입력창 | 100%에 가깝게 또는 고정값 |

- 제목은 보통 짧으므로 행간을 좁게 설정
- 긴 본문은 읽기 편하도록 넉넉하게 설정
- 버튼과 입력창은 높이가 일정하도록 관리

## **5. 자간(Letter Spacing)**

자간은 글자와 글자 사이의 간격이야.

- 자간이 넓으면 글자가 서로 떨어져 보임
- 자간이 좁으면 글자가 밀집되어 보임
- 기본 자간이 자연스러운 폰트라면 굳이 조정할 필요 없음

강의에서는 Pretendard 같은 폰트의 경우 기본 자간을 유지하고, 필요하다면 `0 ~ -0.5px` 정도로 미세하게 조정하는 방법을 설명해.

## **6. 웹에서 사용할 폰트 선택**

웹에서는 크게 시스템 폰트와 웹폰트를 사용할 수 있어.

| 구분      | 시스템 폰트              | 웹폰트                  |
| --------- | ------------------------ | ----------------------- |
| 설치 위치 | 사용자 기기              | 서버에서 다운로드       |
| 로딩      | 빠름                     | 폰트 파일 로딩 필요     |
| 일관성    | 기기에 따라 다를 수 있음 | 비교적 일관된 표현 가능 |

웹폰트를 사용할 때 확인할 사항:

- 상업적 이용이 가능한가?
- 웹 임베딩 라이선스가 있는가?
- 한글·영문·숫자가 자연스럽게 어울리는가?
- 폰트와 Weight를 너무 많이 불러오지는 않는가?

강의에서는 하나의 폰트를 중심으로 사용하고, 필요하다면 제목용과 본문용을 구분하는 방식을 추천해.

## **7. 폰트 두께(Font Weight)**

같은 크기의 글자라도 두께에 따라 강조 정도가 달라져.

| 두께          | 일반적인 사용   |
| ------------- | --------------- |
| Regular (400) | 본문            |
| Medium (500)  | 보조 제목, 강조 |
| Bold (700)    | 주요 제목       |

- 제목은 Bold
- 본문은 Regular
- 보조 정보는 Regular 또는 연한 색상

강의에서는 보통 2\~3개 정도의 Weight 사용을 권장해.

## **8. 텍스트와 배경의 명도 대비**

텍스트와 배경의 대비가 부족하면 가독성이 떨어져.

강의에서 설명하는 WCAG AA 기준:

| 텍스트 종류 | 최소 명도 대비 |
| ----------- | -------------- |
| 일반 텍스트 | 4.5:1          |
| 큰 텍스트   | 3:1            |

강의에서 설명하는 큰 텍스트의 예시:

- 일반 글씨 약 24px 이상
- 굵은 글씨 약 18px 이상

**명도 대비 예시**

연한 회색 텍스트

대비 부족 가능

진한 텍스트

높은 대비

실제 접근성 적합 여부는 배경색과 글자색의 대비 비율로 확인해야 해.

Figma에서는 Stark 플러그인을 사용해 텍스트와 배경의 대비 비율을 확인할 수 있어.

## **9. 프론트엔드 연결**

CSS에서는 폰트 크기, 행간, 자간, 두께를 각각 관리할 수 있어.

```
:root {
  /* Font Size */
  --font-caption: 0.75rem;
  --font-body: 1rem;
  --font-title: 1.25rem;
  --font-headline: 1.5625rem;

  /* Line Height */
  --line-height-heading: 1.4;
  --line-height-body: 1.8;

  /* Font Weight */
  --font-regular: 400;
  --font-medium: 500;
  --font-bold: 700;
}

body {
  font-size: var(--font-body);
  line-height: var(--line-height-body);
  font-weight: var(--font-regular);
}

h1 {
  font-size: var(--font-headline);
  line-height: var(--line-height-heading);
  font-weight: var(--font-bold);
}
```

## **핵심 요약**

1. 타이포그래피의 핵심은 **정보의 중요도에 따른 위계 설정**이다.
2. 폰트 크기는 역할별로 정하고 Typography Scale을 활용한다.
3. 행간은 제목보다 긴 본문에 넉넉하게 설정한다.
4. 자간은 기본값을 우선하고 필요한 경우에만 조정한다.
5. 웹폰트는 라이선스, 한글 지원, 로딩 성능을 확인한다.
6. 폰트 두께는 2\~3개 정도로 제한해 일관성을 유지한다.
7. WCAG AA 기준으로 일반 텍스트 4.5:1, 큰 텍스트 3:1 이상의 명도 대비를 확보한다.

**가장 중요한 개념:** 타이포그래피는 단순히 글자를 예쁘게 만드는 작업이 아니라, 사용자가 정보를 쉽게 읽고 이해하도록 만드는 설계야.
