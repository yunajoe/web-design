# **웹 그래픽의 종류와 이미지 최적화**

## **1. 웹 그래픽의 종류**

웹사이트의 인상은 레이아웃, 타이포그래피, 컬러뿐 아니라 사용하는 그래픽에 따라 달라진다. 서비스의 목적과 전달하려는 메시지에 맞는 이미지 스타일을 선택해야 한다.

| 그래픽 유형     | 특징                                      | 활용                        |
| --------------- | ----------------------------------------- | --------------------------- |
| 라이프스타일 컷 | 제품이나 서비스를 실제 사용하는 모습 표현 | 커머스, 라이프스타일 브랜드 |
| 제품 컷         | 제품 자체의 형태와 디테일 강조            | 전자제품, 상품 소개         |
| 일러스트        | 개념과 기능을 직관적으로 표현             | SaaS, 기능 소개, 브랜딩     |
| 3D 그래픽       | 입체감과 시각적 인상 강조                 | 테크, 스타트업, 랜딩 페이지 |

## **2. 라이프스타일 컷**

- 제품이나 서비스를 실제 사용하는 상황을 보여준다.
- 사용자가 제품을 자신의 일상과 연결해 상상하도록 돕는다.
- 생활용품 및 라이프스타일 커머스에서 활용한다.

## **3. 제품 컷**

- 단순한 배경에서 제품 자체를 강조한다.
- 제품의 형태와 디테일을 명확하게 보여준다.
- 라이프스타일 컷이 사용 경험을 보여준다면, 제품 컷은 제품 자체에 집중한다.

## **4. 일러스트와 아이콘**

- 복잡하거나 추상적인 개념을 직관적으로 표현한다.
- 기능과 장점을 빠르게 이해하도록 돕는다.
- 아이콘, 캐릭터, 모션 등을 활용해 서비스의 특징과 브랜드 분위기를 전달한다.

| 표현   | 의미        |
| ------ | ----------- |
| 번개   | 빠른 속도   |
| 자물쇠 | 보안        |
| 차트   | 데이터 분석 |

## **5. 3D 그래픽**

- 평면 이미지보다 강한 입체감을 전달한다.
- 테크 서비스와 스타트업 랜딩 페이지에서 활용한다.
- 렌더링된 이미지뿐 아니라 실제 3D 인터랙션으로 구현할 수도 있다.
- 과도하게 사용하면 콘텐츠보다 그래픽에 시선이 집중될 수 있다.
- Three.js 등으로 구현할 경우 성능 최적화를 함께 고려한다.

## **6. 그래픽 선택 기준**

하나의 서비스도 다양한 방식으로 표현할 수 있다.

- 서비스를 사용하는 사람의 라이프스타일 이미지
- 실제 제품이나 대시보드 UI
- 기능을 설명하는 UI 그래픽
- 개념을 표현하는 일러스트
- 데이터를 형상화한 3D 그래픽

중요한 것은 그래픽의 스타일보다 **전달하려는 메시지와 목적**이다.

## **7. 다양한 그래픽 표현 방식**

웹에서는 기본적인 이미지 유형 외에도 다양한 그래픽을 활용한다.

- 추상적인 그라디언트
- 셰이더
- 디더링 그래픽
- 인터랙티브 그래픽
- 영상

### **한눈에 비교**

| 구분                | 핵심                | 표현 방식                   | 사용자 반응      |
| ------------------- | ------------------- | --------------------------- | ---------------- |
| 추상적인 그라디언트 | 색과 분위기         | 색상의 부드러운 변화        | 없어도 됨        |
| 셰이더              | 픽셀과 그래픽 계산  | 수학적 계산으로 그래픽 생성 | 실시간 변화 가능 |
| 디더링              | 질감과 명암         | 점이나 픽셀 패턴            | 없어도 됨        |
| 인터랙티브 그래픽   | 사용자와의 상호작용 | 사용자 행동에 따라 변화     | **필수**         |

### **가장 중요한 차이**

- **그라디언트** → 시각적 표현 방식
- **셰이더** → 그래픽을 생성·처리하는 기술
- **디더링** → 이미지를 표현하는 기법
- **인터랙티브 그래픽** → 사용자와 그래픽이 상호작용하는 방식

> 그라디언트 색상 + 셰이더로 만든 물결 효과 + 디더링 텍스처 + 마우스에 반응하는 인터랙션

## **8. 웹 이미지 최적화**

이미지는 시각적 품질뿐 아니라 용량과 해상도도 고려해야 한다.

이미지 파일의 용량이 크면 페이지 로딩 속도가 느려지고 사용자 경험에 영향을 준다.

### **WebP**

- JPG, PNG보다 작은 용량으로 이미지를 저장할 수 있다.
- 사진과 투명 배경을 지원한다.
- 웹 이미지 최적화에 활용한다.

### **이미지 크기 최적화**

- 실제 화면에 표시되는 크기에 맞는 이미지를 사용한다.
- 표시 크기보다 지나치게 큰 원본 이미지는 불필요한 데이터 다운로드를 발생시킨다.
- 데스크톱과 모바일의 표시 크기가 다르면 각 환경에 적합한 이미지 크기를 고려한다.

## **핵심 정리**

1. **이미지의 목적을 먼저 정한다.** 제품, 사용 경험, 기능, 개념 중 무엇을 전달할지에 따라 그래픽 유형을 선택한다.
2. **여러 그래픽을 조합할 수 있다.** 실사, UI, 일러스트, 3D 등을 함께 활용한다.
3. **웹 성능을 고려한다.** WebP 등의 포맷과 적절한 해상도를 사용해 이미지 용량을 최적화한다.
