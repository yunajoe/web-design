# **웹 레이아웃의 기본, 그리드와 브레이크포인트 이해하기**

## **1. 웹 레이아웃의 기본 개념**

웹사이트는 하나의 고정된 화면이 아니다. 데스크톱, 태블릿, 모바일 등 화면 크기에 따라 콘텐츠의 너비와 배치가 달라진다.

따라서 현재 화면뿐 아니라 화면 크기가 변할 때 레이아웃이 어떻게 변경되는지도 고려해야 한다.

## **2. 그리드 시스템(Grid System)**

콘텐츠의 크기와 위치를 일정한 기준으로 정렬하기 위한 구조이다.

**주요 구성 요소**

| 요소                     | 설명                                           |
| ------------------------ | ---------------------------------------------- |
| 컬럼(Column)             | 콘텐츠를 배치하기 위해 화면을 세로로 나눈 영역 |
| 거터(Gutter)             | 컬럼과 컬럼 사이의 간격                        |
| 마진(Margin)             | 화면 가장자리와 콘텐츠 사이의 여백             |
| 콘텐츠 폭(Content Width) | 실제 콘텐츠가 배치되는 최대 너비               |

**12단 그리드**

12단 그리드는 다양한 레이아웃으로 나누기 쉬워 자주 사용한다.

| 구성          | 배치 예시          |
| ------------- | ------------------ |
| 6 + 6         | 2단 레이아웃       |
| 4 + 4 + 4     | 3단 레이아웃       |
| 3 + 3 + 3 + 3 | 4단 레이아웃       |
| 8 + 4         | 본문 + 사이드 영역 |

12단 그리드가 반드시 정답은 아니다. 프로젝트 전체에서 일관된 배치 기준을 만드는 것이 중요하다.

## **3. 브레이크포인트(Breakpoint)**

화면 너비에 따라 레이아웃 구조가 변경되는 기준 지점이다.

예를 들어 카드 4개를 한 줄에 배치하다가 화면이 좁아지면 다음과 같이 변경한다.

`4열 → 3열 → 2열 → 1열`

**브레이크포인트 예시**

| 화면 구분 | 너비        |
| --------- | ----------- |
| 데스크톱  | 1024px 이상 |
| 태블릿    | 768\~1023px |
| 모바일    | 767px 이하  |

위 수치는 절대적인 기준이 아니다. 기기 이름보다 콘텐츠가 자연스럽게 표시되지 않는 지점을 기준으로 설정해야 한다.

**레이아웃 변경이 필요한 상황**

- 내비게이션 메뉴가 한 줄에 들어가지 않는 경우
- 카드가 지나치게 좁아지는 경우
- 제목이 너무 많은 줄로 나뉘는 경우
- 이미지와 텍스트의 비율이 어색해지는 경우

## **4. 반응형 레이아웃 설계**

반응형 디자인은 데스크톱 화면을 단순히 축소하는 작업이 아니다. 화면 크기에 따라 요소의 배치와 크기를 변경하는 작업이다.

**대표적인 변경 방식**

| 요소            | 데스크톱  | 모바일       |
| --------------- | --------- | ------------ |
| 카드 목록       | 4열       | 1열          |
| 이미지 + 텍스트 | 좌우 배치 | 상하 배치    |
| 콘텐츠 여백     | 넓게 설정 | 좁게 설정    |
| 제목            | 한 줄     | 여러 줄 가능 |

모바일에서는 콘텐츠가 쌓이는 순서도 고려해야 한다. 이미지와 텍스트의 배치 순서를 조정해 자연스러운 읽기 흐름을 유지해야 한다.

## **5. 텍스트와 이미지의 반응형 처리**

**텍스트**

- 화면이 좁아지면 줄 수가 늘어날 수 있다.
- 콘텐츠 높이를 고정하면 텍스트가 잘리거나 다른 요소와 겹칠 수 있다.
- 콘텐츠에 맞게 높이가 유연하게 변경되도록 설계해야 한다.

**이미지**

- 16:9, 4:3, 1:1 등 일정한 비율을 유지할 수 있다.
- 화면 크기에 맞춰 이미지 크기를 조정해야 한다.
- 비율을 고정하면 이미지 일부가 잘릴 수 있으므로 주요 피사체가 잘 보이는지 확인해야 한다.

## **6. 반응형 레이아웃 설계 체크리스트**

- 기본 콘텐츠 폭은 얼마인가?
- 몇 개의 컬럼을 사용하는가?
- 컬럼 사이의 거터는 얼마인가?
- 화면 크기에 따라 좌우 마진은 어떻게 변경되는가?
- 어느 지점에서 컬럼 수를 변경하는가?
- 모바일에서 콘텐츠 순서는 어떻게 변경되는가?

## **핵심 요약**

1. 그리드 시스템은 콘텐츠를 일관된 기준으로 정렬하는 구조이다.
2. 그리드는 컬럼, 거터, 마진, 콘텐츠 폭으로 구성된다.
3. 12단 그리드는 2단, 3단, 4단 등 다양한 레이아웃으로 나누기 쉽다.
4. 브레이크포인트는 화면 너비에 따라 레이아웃이 변경되는 기준 지점이다.
5. 반응형 디자인은 화면을 단순히 축소하는 것이 아니라 요소의 배치와 크기를 조정하는 작업이다.
6. 모바일에서는 콘텐츠의 크기뿐 아니라 배치 순서와 읽기 흐름도 고려해야 한다.

**프론트엔드 연결**

- CSS Grid: 컬럼 기반 레이아웃 구성
- `grid-template-columns`: 컬럼 개수와 너비 설정
- `gap`: 컬럼과 행 사이 간격 설정
- `max-width`: 콘텐츠 최대 너비 설정
- `@media`: 브레이크포인트에 따른 레이아웃 변경
