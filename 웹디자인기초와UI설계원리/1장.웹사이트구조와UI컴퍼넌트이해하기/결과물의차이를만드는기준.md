# **1강. AI 시대 웹디자인, 결과물의 차이를 만드는 기준**

디자인베이스 · 웹 디자인 기초와 UI 설계 원리 · 05:43

## **1. 핵심 개념**

**웹디자인은 단순히 예쁜 화면을 만드는 것이 아니라, 사용자와 웹사이트의 목적에 맞게 설계하는 것이다.**

- AI는 디자인 결과물을 만들 수 있지만, 결과물의 좋고 나쁨을 판단하는 것은 디자이너의 역할이다.
- 디자인을 평가하는 기준은 개인의 취향이 아니라 사용자와 웹사이트의 목적이다.
- 좋은 디자인을 위해서는 웹의 구조와 사용 환경을 이해해야 한다.

## **2. 웹디자이너가 고려해야 할 기본 요소**

웹사이트의 종류는 다르지만 공통적으로 고려해야 할 요소가 있다.

| 요소            | 설명                                                |
| --------------- | --------------------------------------------------- |
| 반응형 설계     | 기기별로 정보의 우선순위를 유지하며 레이아웃 재구성 |
| 타이포그래피    | 읽기 쉬운 글자와 텍스트 구성                        |
| 버튼과 인터랙션 | 사용자가 명확하게 행동할 수 있는 UI 설계            |

- 기본적인 웹사이트 구조 학습
- 반응형 레이아웃 연습
- 비주얼 구성 연습

## **5. 실무에서 다룰 핵심 내용**

1. 실제 구현을 전제로 한 레이아웃 설계
2. 다양한 기기 환경에서의 반응형 원리
3. 개발자와 협업할 때 놓치기 쉬운 부분

## **핵심 요약**

**웹디자인에서 기억할 3가지**

1. 디자인은 예쁜 화면보다 목적이 우선이다.
2. 디자인 기준은 디자이너의 취향이 아니라 사용자와 사용 환경에서 출발한다.
3. 좋은 웹디자인은 빠르고, 쉽게 사용할 수 있으며, 목적을 효과적으로 달성하도록 설계하는 것이다.
